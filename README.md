# NLLP-5000

This repository includes the `NLLP-5000` lexical profiling resource for Dutch, alongside the Python programming scripts used to build the resource. The repository consists of two main subdirectories (see separate README in each of the subdirectories for more detailed information):

- `NLLP-5000_compilation`: scripts used to compile the resource
- `NLLP-5000_data`: resource itself
